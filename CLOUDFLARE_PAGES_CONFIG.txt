TELMO PARTILHAS V17 — CONFIGURAÇÃO CORRETA CLOUDFLARE PAGES

O projeto é CLOUDFLARE PAGES + PAGES FUNCTIONS.

NO CLOUDFLARE DASHBOARD:
Workers & Pages -> telmo-partilhas -> Settings -> Builds

1) Root directory
   /

2) Framework preset
   None / No framework

3) Build command
   exit 0
   (também pode ficar vazio; `exit 0` é recomendado pela documentação para sites estáticos que não precisam de build e permite usar Pages Functions.)

4) Build output directory
   .

5) NÃO colocar no Build command:
   npx wrangler deploy

6) Se estiveres num fluxo Git-integrated Pages, NÃO precisas de um comando de deploy manual.
   O próprio Pages faz o deploy depois do build.

7) Se quiseres fazer DEPLOY MANUAL fora do Git integration, no terminal dentro desta pasta usa:
   npx wrangler pages deploy . --project-name=telmo-partilhas

IMPORTANTE
O erro "Missing entry-point to Worker script or to assets directory" mostrado nos logs acontece quando o pipeline executa `wrangler deploy` como se fosse um Worker. Este projeto não deve usar esse comando para o deploy do Pages.
