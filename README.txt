# TELMO PARTILHAS — site estático

Ficheiros principais:
- index.html — website público
- admin.html — painel de administração separado
- style.css — identidade visual / responsive
- admin.css — estilo do painel
- script.js — funcionamento do website
- admin.js — gestão do conteúdo

## Como abrir
Abra `index.html` diretamente no navegador. Não precisa de Node.js, PHP ou servidor.

## Admin
Abra `admin.html`.
Palavra-passe inicial: `admin123`
Pode ser alterada em Admin > Configurações.

## Armazenamento
Tudo é guardado no `localStorage` do navegador. Fotografias escolhidas através do painel podem ser guardadas localmente no próprio navegador como base64.

## Nota
A autenticação LocalStorage/sessionStorage não é segurança de servidor. Quando quiseres uma solução online com contas reais, o mesmo modelo pode ser ligado a uma API/backend.
