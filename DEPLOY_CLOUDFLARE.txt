TELMO PARTILHAS V16 — PUBLICAÇÃO CORRETA NO CLOUDFLARE PAGES

O erro mostrado no log acontece porque o projeto é Cloudflare Pages, mas o comando usado é:
  npx wrangler deploy

Esse comando é para Workers. Para Pages, usa-se:
  npx wrangler pages deploy . --project-name=telmo-partilhas

NO CLOUDFLARE PAGES:
- Build command: deixar vazio, porque este projeto não precisa de build.
- Build output directory: .
- Se houver um campo de Deploy command, usar:
  npx wrangler pages deploy . --project-name=telmo-partilhas

ALTERNATIVAMENTE, em CI/CD:
  npm install
  npm run deploy

IMPORTANTE:
- NÃO usar `npx wrangler deploy` neste projeto Pages.
- A pasta `functions/` contém as Pages Functions e é publicada pelo fluxo Pages.
- `admin.html` e `index.html` ficam na raiz.
- O projeto usa D1 pelo binding `DB`.
- O R2 usa o binding `MEDIA` quando configurado.
- O secret do Admin é `ADMIN_PASSWORD`.
